# Worksheets

Each `.md` file here is one numbered worksheet. On every deploy, the website adds new sheets
(and updates changed ones) and assigns each sheet to every student in its batch.

```
---
number: 12
title: Fractions practice
batch: Class 6
subject: Maths
due: 2026-11-05
---
1. Add 2/3 and 3/4.
2. ...
```

`number`, `title` and `batch` are required. `subject` and `due` (YYYY-MM-DD) are optional.
